# Satzwerk

Satzwerk is a closed-loop German writing production app built on Second Language Acquisition (SLA) principles. While flashcards drill lexical recall, Satzwerk trains  **active morphosyntanctic production** through a five-step feedback loop ('Task -> Draft -> Graduated Feedback -> Clean Rewrite -> Error Ledger')

The problem it tries to solve is knowing a rule (declarative knowlegde) and deploying it while writing (procedural knowledge). For example, a B1/B2 learner can pass a multiple-choice quiz on subordinate clause word order, yet still get them wrong while writing an email. This happens due to 3 cognitive reasons: 

1. Avoidance: When given the choice, the brain chooses the path of least resistance and sticks to safe simple sentences.  
2. Attention Overload: Working memory is finite. If a learner is trying to invent a scenario, remember the German word for "faucet", and figure out case endings, syntax is the first thing to drop. 
3. Passive Correction: When an app or teacher simply hands a corrected sentence, the learner nods, copies it down and forgets about it because the brain never had to do the retrieval work.
